## Что делает функция

Один стандартный GraphQL introspection-запрос к уже подтверждённому
`https://ows.goszakup.gov.kz/v3/graphql` читает четыре известных типа:
`Lots`, `PlnPoint`, `TrdBuy`, `LotsFiltersInput`. Используются стандартные
`__type`, `fields(includeDeprecated: true)`, `inputFields`, `name`, `kind`,
`description`, `type/ofType`, `isDeprecated`, `deprecationReason`.
Новых бизнес-полей Goszakup не задаётся и не предполагается.

Отчёт содержит реальные **возвращённые API** имена полей и формы типов,
например список или non-null; описания и пометки deprecated доступны для
ручной сверки. `requiresSemanticReview` — только поисковая подсказка по словам,
не доказательство значения поля. Описания более 1000 символов сокращаются и
помечаются `descriptionComplete: false`; их нельзя объявлять полной спецификацией.
Редактирование секретов происходит до сокращения и записи отчёта.
`introspectionShapeVerified: true` означает только успешную структурную проверку
полученного пакета; не означает, что поле национального режима найдено/верифицировано.

Неизвестный тип, дубли имён, неверная форма поля/типовой ссылки, усечённая
цепочка типов или превышение лимитов запрещают выдачу частично подтверждённого
инвентаря. Максимум 200 полей каждого типа, JSON инвентаря ≤120 000 символов.
Не проверяются все другие типы, REST-интерфейсы или реестры: отсутствие слова
в этих четырёх типах не доказывает отсутствия официального пути вообще.

Любой результат сохраняет `nationalFieldVerified: false`, `nationalRegime:
UNVERIFIED`, `decision: HOLD_NATIONAL`, `mvpReady: false`. Схема сама по себе
не доказывает значение, актуальность и привязку к конкретному лоту.
Нет вызовов Lots/Plans для сбора данных, чтения страниц портала, скрейпинга
или передачи Bearer на другой хост. Отсутствие интроспекции/запрет API также
даёт неизвестный результат, без выдуманного запасного маршрута.

## Квоты, данные и запуск

Максимум четыре HTTP-попытки с учётом retries, общий с PR #20 и пилотом
счётчик `TENDER_PILOT_QUOTA` (200 за скользящие 24 часа), script lock,
проверки 30 секунд до попытки и после ответа. Уже выполняющийся UrlFetch
нельзя прервать. HTTP ошибки и поздние ответы не становятся доказательствами.
Старые функции без этого счётчика нельзя считать включёнными в общую квоту.

Изменяется **только служебный квотный счётчик**. Все Sheets, включая G:J/K/L,
прочие Properties, fingerprint, токен, курсоры и триггеры сохраняются.
Не требуются доказанная timezone, активные статусы или готовность sync:
это диагностика схемы, она не создаёт proof и не снимает `FULL_SCAN_DISABLED`.
Не вызываются setup, sync, pilot, TS или installDailyTrigger.

После разрешённого владельцем manual `prepare` → backup/diff review → `publish`
с повторным чтением проекта можно отдельно разрешить ручной запуск
`inspectTenderNationalSchema` через редактор Apps Script. Используется уже
сохранённый GOSZAKUP_TOKEN; его не нужно выводить или пересылать.
Не изменять существующие настройки для искусственного прохождения диагностики.
В журнале — `NATIONAL_SCHEMA_JSON_PART_1`, `_2`, …, по 4000 символов;
для полного JSON соединить содержимое частей по номеру, удалив только префиксы.
Не терять части и не считать отсутствующие поля доказанным «Нет».

Для следующего этапа нужны очищенный реальный отчёт этой функции и официальные
страницы трёх конкретных лотов с текущей отметкой, датой/версией и ссылкой.
Наличие потенциального поля требует официального подтверждения смысла и
проверки значения на лотах; КТРУ, deprecated, правило без актуального списка,
устаревшая/противоречивая отметка не дают `SKIP` или `PASS_TO_TS`.
Полный классификатор и работа с ТС остаются заблокированы до этих доказательств.

## Проверки и откат

Все ответы тестов синтетические; имена типов/полей берутся из сохранённых
официальных SDL. Тестовые описания не являются реальной спецификацией API.
**209 локальных тестов прошли**, без ошибок и пропусков; добавлен 21 сценарий.
Пробное объединение с PR #19 через `git merge-tree` прошло без конфликтов;
временный архив общего дерева PR #19/#20/этого PR прошёл **222 теста**,
без ошибок и пропусков. Реального merge в main не выполнялось.
Проверяются целостность типов, malformed/частичные ответы, ограничения объёма,
deprecated, отсутствие автоматического допуска, redaction, квота/retry,
CONNECT/HTTP/GraphQL/таймаут и сохранность Sheets/Properties кроме счётчика.

```sh
node --test tests/core.test.cjs tests/upload.test.cjs tests/actions.test.cjs
git diff --check
```

CI использует существующий read-only workflow, без публикации и Secrets.
Откат после будущей разрешённой публикации — предыдущая проверенная версия
Pilot.gs через manual prepare/publish. Миграций Sheets нет; учтённую квоту
не обнулять. В этом PR manifest, scopes и workflows не меняются.

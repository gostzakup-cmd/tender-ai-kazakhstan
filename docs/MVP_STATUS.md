## Блокеры боевого запуска

1. Требуется реальный авторизованный диагностический отчёт. Токен
   пользователь добавляет в Apps Script, не передаёт в чат.
2. Не подтверждены зона дат без смещения, устойчивая ссылка лота и полный
   список активных кодов. Они явно настраиваются, а не выдумываются.
3. Нужна сверка реальной схемы, Plans/pointList, isDeleted и pageInfo;
   отличие контракта вызывает остановку, а не молчаливый пропуск.
4. Не исполнены Google setup/self-tests/полный sync/повтор с обновлениями
   и следующее автоматическое daily выполнение.
5. Масштаб: полный реестр сканируется каждый цикл и Sheets читается/
   перезаписывается на каждой странице. Требуется замер; если обход
   больше суток, требование «все новые каждый день» ещё не обеспечено.
   Инкрементальная стратегия не заявляется реализованной.

Блокер доступа к официальной документации снят: help, schema и developer
доступны. CONNECT 403 не является ошибкой API-токена. Блокер документации
суммы/количества также снят через Lots.amount/count V3.

Порядок: установка → setup → self-tests → GOSZAKUP_TOKEN → диагностика
V3 и справочника → проверка отчётов/настройки → повтор диагностики →
полный sync и сверка → daily trigger → замер следующего выполнения.
Точные действия и названия свойств приведены в README.md.

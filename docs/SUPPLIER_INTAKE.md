# Supplier evidence intake — Issue #30

`intakeTenderSupplierOffers(shortlist, observations, nowIso)` accepts **supplied** observations from Kazakhstan, Russia and China distributors/manufacturers/marketplaces, one exact supplier and product per submitted lot. It has no network privileges and does **not** scrape websites, browse catalogs, look up suppliers or fetch prices. No provider or SKU is fabricated.

An observation supplies lotId, offerId, provider, origin, sourceKind, productUrl, supplierId/name, brand/model/partNumber/unit, unitPrice/currency, availableQuantity, leadTimeDays and separate PRICE/STOCK/DELIVERY unreviewed evidence snapshots (HTTPS URL, page locator, sha256, observedAt). Every source is only a **claim** until separately checked. `status=UNREVIEWED` is mandatory. Neither self-declared `CONFIRMED` nor an HTTPS URL promotes it. A structured work queue returns `PENDING_REVIEW` or `REVIEW` with explicit reasons. A separate trusted source-review adapter must inspect the real source bytes, page content, supplier identity/ownership and independence, dated prices, stock and delivery, and map verified facts to the existing `evaluateTenderResearch` evidence contract. Thus `verifiedQuotes=0`, `authorizedResearch=false` and `nationalDecision=HOLD_NATIONAL` remain explicit; no commercial GO is possible.

`previewTenderSupplierIntakeCsv(report)` returns a spreadsheet-formula-safe CSV *string*, including exact URL/quantity/price and reasons. It does not write a file or Sheets. The first row is always a header. CSV contains potentially commercial input; handle as confidential and only save/share with explicit owner permission.

Limits: at most 30 shortlist lots, 30 observations per lot, 24h evidence freshness, explicit currencies, supported source categories and HTTPS page URLs. Provider labels are not independent proof that the provider has stock or that the unit price is still valid. Financial calculation, currency conversion, tax, delivery cost and margin are intentionally not inferred. The original research engine still requires three **independently reviewed** offers and all cost categories before any conditional GO. No paid services, sheet writes, Apps Script publishing or trigger changes. No live supplier data was gathered by this PR.

Development verification: `node --test tests/*.test.cjs` in GitHub Actions. Synthetic tests are not real supplier verification.
